# iFusen

自由配置型のホワイトボードです。付箋を思いついた場所に置き、位置関係そのものを使って考えるためのツールで、Kanbanやタスク管理ツールのような決まった枠組みは持ちません。

## 使い方

`iFusen.html` をブラウザで開くだけで動きます。ビルドや外部依存（npm、CDN、サーバ等）は不要です。

### 操作一覧

| 操作 | 内容 |
| --- | --- |
| ホイール | ズームイン・アウト（カーソル位置中心） |
| 選択ツール / 付箋ツール + 空白をドラッグ | キャンバスをパン |
| Space + ドラッグ / 中クリックドラッグ | ツールに関わらずパン |
| 付箋ツール + クリック | 付箋を新規作成 |
| 付箋をドラッグ | 付箋を移動（最前面に移動） |
| 付箋をクリック | クリックした位置から本文を編集 |
| 選択中の付箋のミニツールバー | 色変更・削除 |
| ペンツール + ドラッグ | 手書き線を描画 |
| 消しゴムツール + ドラッグ | 触れた線を1本ずつ消去 |
| V / N / P / E | 選択 / 付箋 / ペン / 消しゴムに切り替え |
| Escape | 本文編集を終了 / 選択を解除 |
| Delete / Backspace | 選択中の付箋を削除 |
| ツールバーの表示リセットボタン | パン位置とズーム率を初期状態に戻す |
| 右上のごみ箱ボタン | すべての付箋と描画を消去（確認ダイアログあり） |

## できること

- **キャンバス**: 広さの制限がないホワイトボード。パンとズーム（15%〜400%）に対応
- **付箋**: 任意の位置に作成し、ドラッグ移動・本文編集・色変更（6色）・削除ができます。グリッドスナップはなく、位置は完全に自由です
- **手書き**: ペンで線を描き、消しゴムで線単位に消去できます
- **自動保存**: 付箋の内容・位置・色、描画内容、表示位置とズーム率をブラウザの `localStorage` に保存し、次回アクセス時に復元します
- **ファイル保存・復元**: `.ifusen` ファイルへの書き出しと読み込み

## データの扱いと注意点

保存はすべて手元のブラウザ内で完結します。サーバへの送信や同期は行いません。

- 自動保存先はブラウザの `localStorage` です。**別のブラウザ・別の端末とは共有されず、ブラウザのデータ消去やプライベートウィンドウの終了で失われます。** 残したい内容はツールバーの保存ボタンから `.ifusen` ファイルに書き出してください。
- 自動保存に失敗した場合（保存容量の不足など）は警告を表示します。表示されたらファイルへの書き出しで退避してください。
- Undo はありません。付箋の削除は確認なしで即座に反映され、取り消せません。「すべて消去」とファイルからの復元（現在の内容を置き換えます）は確認ダイアログの後に実行されます。

## デプロイ

`main` ブランチの `iFusen.html` は、`.github/workflows/pages.yml` により GitHub Pages へ自動デプロイされます（`iFusen.html` を `index.html` として公開）。
