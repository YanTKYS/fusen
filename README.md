# iFusen

自由配置型のホワイトボードUIプロトタイプです。Kanbanやタスク管理ツールではなく、思いついた場所に付箋を置き、自由な位置関係を作りながら空間を使って考えるためのツールを目指しています。

## 特徴

- **自由なキャンバス**: パン（ドラッグ）・ズーム（ホイール、カーソル位置中心）に対応した広いホワイトボード
- **付箋**: 任意の位置に新規作成し、自由にドラッグ移動・本文編集・色変更・削除が可能（グリッドスナップなし）
- **自由描画**: ペンでの手書き線と、消しゴムによる描画の削除
- **操作モード**: 選択 / 付箋 / ペン / 消しゴムを切り替えるコンパクトなツールバー
- **自動保存**: 付箋の内容・位置・色、描画内容、キャンバスの表示位置・ズーム率を `localStorage` に自動保存し、再訪時に復元（保存できなかった場合は警告を表示）
- **ファイル保存・復元**: `.ifusen` ファイルへの書き出しと読み込み
- **全消去**: 確認ダイアログ付きの「すべて消去」機能

## 使い方

`iFusen.html` を直接ブラウザで開くだけで利用できます。ビルドや外部依存（npm、CDN、サーバ等）は不要です。

### 操作方法

| 操作 | 内容 |
| --- | --- |
| 選択ツール / 付箋ツール + 空白ドラッグ | キャンバスをパン |
| ホイール | ズームイン・アウト（カーソル位置中心） |
| 付箋ツール + クリック | 付箋を新規作成 |
| 付箋をドラッグ | 付箋を移動 |
| 付箋をクリック | 本文を編集 |
| 選択中の付箋のミニツールバー | 色変更・削除 |
| ペンツール + ドラッグ | 手書き線を描画 |
| 消しゴムツール + ドラッグ | 線を消去 |
| Space + ドラッグ / 中クリックドラッグ | ツールに関わらずパン |
| キーボード: V / N / P / E | 選択 / 付箋 / ペン / 消しゴムに切り替え |

## デプロイ

`main` ブランチへの `iFusen.html` の変更は、`.github/workflows/pages.yml` により GitHub Pages へ自動デプロイされます。
